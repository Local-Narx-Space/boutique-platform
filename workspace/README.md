# Open all eight repositories in one editor

This folder contains an optional VS Code workspace, not another deployment
configuration or Git repository. Clone all eight repositories beside each other,
then open [boutique.code-workspace](boutique.code-workspace) in VS Code. Its
relative paths locate those sibling repositories and hide generated tool caches.
Each repository keeps its own commits and remote.

For architecture, deployment and operations, use the single [project guide](https://github.com/Local-Narx-Space/boutique-ci/blob/main/DOC.md).
